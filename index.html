Why Numio

Built for my own phone first

Every Numio app replaces something I used every day and wanted to be better. If it isn't good enough for me, it doesn't ship.

Nothing to sell you

No ads, no analytics, no accounts. The apps work fully offline and ask only for the permissions they need.

Open all the way

Every line of code is on GitHub under GPL-3.0. Read it, build it yourself, or send a fix.
